# Gorba Batman — V5 Modern UI

این نسخه از پایه V5 فعلی ساخته شده و قابلیت‌های قبلی حفظ شده‌اند.

## تغییرات این نسخه
- ظاهر سه‌ستونه شبیه طرح مرجع: فهرست گفتگوها، چت، پنل اطلاعات کاربر
- نوار پروفایل پایینِ ستون گفتگوها ثابت می‌ماند
- نوار نوشتن پیام پایین چت ثابت می‌ماند و در F11 از صفحه بیرون نمی‌رود
- دکمه‌های پایین پیام شامل پاسخ، هدایت، ویرایش، سنجاق، گزارش 😠، ذخیره و حذف هستند
- «هدایت» پیام را با متن و رسانه به یک کاربر انتخاب‌شده می‌فرستد
- پنل اطلاعات سمت راست دکمه‌های پروفایل، تنظیمات چت، گالری، اعلان، سنجاق و ذخیره دارد
- ارسال عکس/ویدیو/فایل دوباره مقاوم‌سازی شده و آپلود در صورت خطای موقت یک بار retry می‌شود
- ساختار API و Durable Objectهای نسخه V5 دست‌نخورده باقی مانده است

## نکته
این نسخه جایگزین نسخه COMPLETE21 خراب‌شده نیست؛ پایه آن همان V5 + قابلیت‌های تثبیت‌شده قبلی است.
