# گوربا بتمن - چت خصوصی

نسخه اولیه دارای:
- ثبت نام با نام نمایشی
- جستجوی کاربران
- انتخاب کاربر از نتایج
- اتاق WebSocket جداگانه برای هر جفت کاربر
- ارسال پیام فقط در اتاق همان دو کاربر

نکته: این نسخه هنوز احراز هویت واقعی، تاریخچه دائمی پیام‌ها، پروفایل و ارسال تصویر ندارد. چون ورود فقط با نام نمایشی است، هرکس می‌تواند نامی را وارد کند؛ برای نسخه جدی باید سیستم حساب کاربری و احراز هویت اضافه شود.update
