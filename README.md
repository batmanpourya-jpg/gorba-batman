# گوربا بتمن - نسخه جستجوی کاربران

این نسخه علاوه بر چت زنده، نام‌های نمایشی کاربران را در Durable Object ذخیره می‌کند و امکان جستجوی نام کاربران را فراهم می‌کند.

## قابلیت‌ها
- ورود با نام نمایشی
- ثبت نام نمایشی در ذخیره‌سازی Durable Object
- جستجوی کاربران با بخشی از نام
- چت زنده WebSocket

## نکته
این هنوز نسخه اولیه است. انتخاب کاربر در نتایج جستجو فعلاً فقط نام او را انتخاب می‌کند؛ چت خصوصی واقعی، حساب کاربری امن، ارسال تصویر و تاریخچه دائمی پیام‌ها در مراحل بعدی اضافه می‌شوند.
