# گوربا بتمن — نسخه آنلاین

این نسخه یک پیام‌رسان وب واقعیِ چندکاربره است:
- ورود بدون شماره، با نام و عکس
- جست‌وجوی کاربران
- چت زنده با WebSocket
- ذخیره پیام‌ها در فایل JSON
- آپلود عکس پروفایل

## اجرا روی کامپیوتر
1. Node.js نصب باشد.
2. در پوشه پروژه اجرا کنید:
   npm install
   npm start
3. مرورگر را روی http://localhost:3000 باز کنید.

## نکته مهم
این نسخه برای شروع و تست است. برای انتشار عمومی بهتر است احراز هویت، قوانین دسترسی، محدودیت آپلود، ضداسپم، دیتابیس واقعی و ذخیره‌سازی ابری اضافه شود.
