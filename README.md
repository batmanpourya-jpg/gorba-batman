# گوربا بتمن — نسخه اصلی

نسخه اصلی پیام‌رسان دوستانه با Cloudflare Workers + Durable Objects + SQLite.

## امکانات واقعی
- ورود فقط با نام، بدون شماره و Google
- جستجوی کاربران با نام
- پروفایل و عکس پروفایل
- فهرست خودکار همه کاربران ثبت‌شده در بخش «رفیق‌ها و گفتگوها»؛ بعد از اضافه‌شدن یک نفر لازم نیست دوباره جستجو شود
- چت خصوصی دونفره
- ارسال و دریافت پیام متنی
- WebSocket برای نمایش لحظه‌ای پیام‌ها
- ذخیره دائمی پیام‌ها در SQLite
- تاریخچه گفتگو
- آخرین پیام و زمان آن در فهرست
- شمارنده پیام خوانده‌نشده
- وضعیت آنلاین/آفلاین بر اساس heartbeat
- حذف پیام توسط فرستنده
- رابط موبایل و دسکتاپ
- مدیریت خطا
- عدم استفاده از `.one()` در queryهایی که ممکن است صفر نتیجه داشته باشند

## Deploy
1. فایل ZIP را باز کن.
2. پروژه را به GitHub متصل‌شده به Cloudflare Workers بده.
3. Deploy کن.
4. بعد از ورود با دو نام متفاوت، هر دو نام باید در «رفیق‌ها و گفتگوها» دیده شوند.
5. با باز کردن یک نفر، گفتگو ساخته می‌شود و پیام‌ها ذخیره می‌شوند.

## تست اصلی
A وارد می‌شود → B وارد می‌شود → A بدون جستجو B را در فهرست می‌بیند → A چت را باز می‌کند → پیام می‌فرستد → B همان لحظه پیام را می‌بیند → بعد از refresh تاریخچه باقی می‌ماند.
