# Gorba Batman — Rebuild

یک پیام‌رسان وب مستقل با الهام از الگوی نسخه وب پیام‌رسان‌ها، اما با هویت و رابط کاربری مستقل.

## امکانات این نسخه
- ورود و ثبت‌نام بدون شماره تلفن (username + password)
- حساب پایدار روی چند دستگاه با session cookie
- لیست گفتگوها با آخرین پیام و unread
- پیام‌رسانی خصوصی حتی وقتی طرف مقابل آفلاین است
- دریافت زنده پیام با WebSocket
- جستجوی کاربران
- تم‌های مختلف
- رابط دسکتاپ و موبایل واکنش‌گرا
- Durable Object SQLite برای ذخیره حساب، گفتگو و پیام

## Deploy
```bash
npm install
npx wrangler login
npx wrangler deploy
```

## نکته رسانه
برای عکس/ویدیو پایدار بین دستگاه‌ها، یک Storage جدا (مثلاً R2 یا Supabase Storage) باید وصل شود. این نسخه عمداً بدون وابستگی اجباری به R2 ساخته شده تا Deploy به billing R2 وابسته نباشد.
