# Gorba Batman — Media & Theme Update

این نسخه روی نسخه FIX_LOGIN ساخته شده و این امکانات را اضافه می‌کند:

- ارسال عکس و فیلم تا ۲۰ مگابایت از داخل چت
- ذخیره فایل‌ها به‌صورت chunk در SQLite Durable Object؛ هر chunk کمتر از محدودیت ۲MB است
- نمایش عکس و پخش فیلم داخل گفتگو
- تم‌های Midnight / Dark / Light / Purple
- پس‌زمینه پیش‌فرض، آبی، گرادیان و انتخاب تصویر از گالری
- ذخیره تنظیمات ظاهر روی حساب کاربر، نه فقط مرورگر
- کلیک روی نام یا عکس شخص در بالای چت برای نمایش پروفایل، بیو و آخرین بازدید
- migration خودکار ستون‌های جدید کاربران
- بدون استفاده از SQL `.one()` در مسیرهای جدید

## تست پیشنهادی
1. دو کاربر وارد شوند.
2. یکی روی نام نفر مقابل کلیک کند و بیو/آخرین بازدید را ببیند.
3. از 📎 یک عکس کوچک بفرستد.
4. یک ویدئوی کوتاه زیر ۲۰MB بفرستد.
5. صفحه را refresh کند و رسانه‌ها همچنان قابل مشاهده باشند.
6. تم و پس‌زمینه را تغییر دهد، خارج شود و دوباره وارد همان حساب شود؛ تنظیمات باید برگردند.

### نکته فنی رسانه
SQLite-backed Durable Objects برای هر BLOB/row حدود ۲MB محدودیت دارند، بنابراین فایل‌های رسانه‌ای این نسخه به قطعات کوچک‌تر تقسیم می‌شوند. برای فایل‌های بسیار بزرگ یا مقیاس عمومی، R2 مناسب‌تر است.
