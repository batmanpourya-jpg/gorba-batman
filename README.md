# گوربا بتمن — نسخه رفع ورود با ID

این نسخه همان ظاهر قبلی را حفظ می‌کند و مشکل ورود با ID را مقاوم‌تر می‌کند:

- ورود موفق دیگر بلافاصله یک درخواست دوم برای بررسی حساب نمی‌زند؛ اطلاعاتی که `/api/login` تأیید کرده مستقیماً استفاده می‌شود.
- در رفرش صفحه، اگر حساب واقعاً پیدا نشود (404)، کاربر به صفحه ورود برمی‌گردد.
- در خطای موقت شبکه، اطلاعات ذخیره‌شده‌ی حساب پاک نمی‌شود.
- `@` ابتدای ID به‌صورت خودکار حذف می‌شود.
- ID در سرور و کلاینت یکدست lowercase می‌شود.
- ثبت حساب همچنان ID را یکتا نگه می‌دارد.
- ظاهر تنظیمات، عکس پروفایل و کاور نسخه قبلی حفظ شده‌اند.

نکته مهم: حساب‌هایی که در یک نسخه/namespace قدیمی و جداگانه ساخته شده‌اند، لزوماً در Directory جدید وجود ندارند؛ در این حالت باید همان ID را یک بار در نسخه جدید ثبت کرد.
