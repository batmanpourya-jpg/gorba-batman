# Gorba Batman — V5 Base + Updates 7-21 (Stable Repair)

این نسخه از **Update 5 Stable** به‌عنوان پایه ساخته شده و قابلیت‌های Updateهای 7 تا 21 به‌صورت مرحله‌ای روی همان معماری اضافه شده‌اند.

## موارد اضافه/اصلاح‌شده
- ورود با نام نمایشی بدون شماره تلفن
- جستجوی کاربر با بخشی از نام
- چت خصوصی و گروهی
- گروه‌ها، مدیر/مالک، افزودن عضو و بی‌صدا کردن
- متن، عکس، ویدیو، فایل/PDF و پیام صوتی
- پیام صوتی در گروه نیز فعال است
- پاسخ، ویرایش، حذف برای همه/من، سنجاق و ذخیره پیام
- پیام‌های ذخیره‌شده با امکان ارسال مجدد متن و رسانه
- رسید ارسال/خوانده‌شدن و وضعیت تایپ
- گالری رسانه چت
- بارگذاری پیام‌های قدیمی هنگام اسکرول به بالا
- جستجوی داخل چت و جستجوی سراسری کاربران/پیام‌ها
- اعلان مرورگر
- ظاهر روشن/تاریک، رنگ اصلی و پس‌زمینه اختصاصی چت
- تماس صوتی/تصویری WebRTC
- گزارش خطا/گزارش کاربر
- پنل مدیریت با رمز مدیر، آمار، کاربران، گزارش‌ها، تاریخچه اقدامات و کلمات هشدار
- فعال/خاموش کردن کلمات هشدار و ثبت اقدامات مدیریتی
- وضعیت و پیگیری گزارش‌ها
- حریم خصوصی پروفایل: بیو، آخرین بازدید و عکس
- migration امن برای ستون‌های قدیمی SQLite
- **نوار پایین پروفایل ثابت و قابل مشاهده** در حالت عادی و موبایل
- استفاده از `100dvh` و flex layout برای جلوگیری از جابه‌جایی نوار پایین در حالت تمام‌صفحه

## تست‌های انجام‌شده

- `node --check src/index.js`
