# گوربا بتمن — Stable V5

این نسخه عمداً از **Update 5** به‌عنوان پایه استفاده می‌کند چون پایدارتر و ساده‌تر است.

### چیزهایی که نگه داشته شده
- ورود فقط با نام نمایشی، بدون شماره و گوگل
- جستجوی کاربران و نمایش همه کاربران در فهرست گفتگو
- چت خصوصی، پیام، ویرایش، حذف، پاسخ، سنجاق و وضعیت خوانده‌شدن
- عکس/ویدیو/فایل و پیام صوتی در چت خصوصی
- گالری رسانه‌ای چت
- ظاهر تاریک/روشن، رنگ اصلی و پس‌زمینه چت
- ساخت گروه، افزودن عضو، مدیر/مالک و بی‌صدا کردن گروه
- تاریخچه پیام با بارگذاری پیام‌های قدیمی هنگام اسکرول به بالا

### تعمیرات این نسخه
- سازگاری دیتابیس با ستون‌های نسخه‌های جدیدتر
- جستجوی نام با تطبیق بخشی از نام، نه فقط ابتدای آن
- قفل‌کردن اسکرول صفحه برای رفتار طبیعی‌تر پیام‌رسان
- بدون پنل مدیریت و قابلیت‌های سنگین Update 7 تا 21، برای اینکه ورود و هسته پیام‌رسان پایدار بماند

> این نسخه برای جایگزینی مستقیم کد Worker فعلی طراحی شده است و جدول‌های موجود را حذف نمی‌کند.
